Abstract

⚡

Core Mission
IntelliQ is a full-stack intelligent queue management platform designed to eliminate physical wait times at hospitals, banks, and government offices across India.

🤖

AI Engine
Integrates AI-driven time slot recommendations using crowd-level prediction models (Random Forest / Linear Regression) trained on historical booking patterns.

📱

Tech Stack
Built with Flutter (Dart) for cross-platform frontend (Android, iOS, Web) and .NET 8 ASP.NET Core for the backend REST API with SQL Server persistence.

🎯

Scale & Scope
Supports 4 user roles (User, Admin, Staff, Super Admin). Pre-loaded with 1 lakh+ real Indian service locations — zero dependency on paid map APIs.

🔐

Security & Architecture
JWT + BCrypt role-based authentication. Clean service-layer architecture with 40+ REST endpoints, 9 database tables, and 29 Flutter screens.

📲

Key Features
Real-time queue tracking, QR-code digital tokens, smart search with suggestions, live counter management, and role-specific analytics dashboards.

Problem Statement

01
Wasted Hours in Physical Queues
Indians spend an estimated 6+ billion hours per year standing in queues at hospitals, banks, and government offices — a massive productivity drain.
02
Zero Visibility & Transparency
Customers have no way to know their queue position, estimated wait time, or how crowded a location is before physically arriving.
03
Outdated Paper Token Systems
Manual paper slips are error-prone, non-trackable, unsustainable, and offer absolutely zero remote or mobile monitoring capability.
04
Staff & Counter Inefficiency
No data-driven tools for admins to manage counter allocation, peak-hour staffing, or identify bottlenecks in real time.
05
No Smart Scheduling Intelligence
Users receive zero guidance on when to visit to avoid crowds — leading to peak-hour overload and off-peak underutilization.
06
Post-COVID Health & Safety Risk
Physical crowding at service centers continues to pose public health risks. Digital-first queue management is no longer optional — it's essential.

Current Existing Systems & Their Problems

IoT-Based System
Smart Queue (IoT + LCD)
  • Requires expensive hardware at each location
  • No remote mobile tracking — must be physically present
  • No AI or crowd prediction capability
  • Single-domain only; no cross-organization support
  • Complex installation and maintenance overhead
Appointment Apps
Google Reserve / Practo
  • Limited to partnered businesses only
  • No live real-time queue position tracking
  • No AI-based slot recommendation engine
  • No staff-side counter & queue management
  • Requires expensive third-party API subscriptions
Domain-Specific Apps
Hospital / Bank Queue Apps
  • Works for one domain only (hospital OR bank)
  • No multi-role dashboard (Admin, Staff, SuperAdmin)
  • No QR-code digital token generation
  • No cross-platform support (Android, iOS, Web)
  • No analytics, AI prediction, or data insights
💡

IntelliQ's Solution: A single unified platform combining real-time queue tracking + QR digital tokens + AI crowd prediction + multi-role dashboards + 1L+ pre-loaded Indian locations — all in one production-ready cross-platform app. No hardware. No paid APIs. No boundaries.

AI & ML Model — Smart Slot Prediction

🌲 Random Forest Regressor

Primary Model
  • Ensemble of 100+ decision trees trained on booking data
  • Features: Hour of day, Day of week, Service type, Location
  • Predicts: CrowdLevel (0.0–1.0) for each time slot
  • High accuracy for non-linear crowd patterns
  • Resistant to overfitting via bagging technique
  • Handles categorical features (service type) naturally
  • Feature importance: identifies peak-hour drivers

📈 Linear Regression

Baseline / Fallback Model
  • Simple, interpretable crowd prediction baseline
  • Features: Time slot index, Historical avg crowd per hour
  • Predicts: Continuous crowd score for slot ranking
  • Used when training data is limited (new locations)
  • Fast inference — sub-millisecond predictions at scale
  • Easily explainable to stakeholders & evaluators
  • RMSE evaluated against Random Forest for model selection
